This panel needs a Supabase project before it can do anything. The public site is unaffected: the events page keeps its "ring the workshop" message until this is set up.

  1. Create a Supabase project in the London (eu-west-2) region. The region is permanent.
  2. Run supabase/schema.sql in the SQL editor.
  3. Turn off sign-ups under Authentication, then create your own user and tick Auto Confirm.
  4. Add yourself to public.admins using the snippet at the top of the schema.
  5. Paste the project URL and anon key into assets/js/sb-config.js.
  6. Run supabase/tests/rls.sql and check every row says passed.

The full walkthrough is in docs/EVENTS-SETUP.md.
